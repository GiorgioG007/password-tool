A lightweight, zero-dependency command-line tool built in Python to generate strong, randomized passwords and evaluate password security.

---

## ✨ Features

* **🎲 Secure Password Generator:** Generates strong passwords of custom length using uppercase letters, lowercase letters, digits, and special characters.
* **🛡️ Password Strength Checker:** Analyzes any existing password based on length and character diversity and assigns a clear rating (**Weak**, **Medium**, or **Strong**).
* **💡 Improvement Feedback:** Provides actionable suggestions on how to make weak passwords safer.
* **⚡ Zero External Libraries:** Uses only Python's built-in `random` and `string` modules—no `pip install` required.
